# Asklear MCP Server

Asklear MCP currently provides monthly JD e-commerce sales data. Other datasets may be available depending on the user's onboarding entitlement.

Asklear provides a hosted [Model Context Protocol](https://modelcontextprotocol.io) (MCP) service through which authorized AI agents can query structured monthly Chinese e-commerce sales data, including post-discount sales (GMV), units, and average selling price.

## Getting access

During the beta, access is by invitation or application. Apply or sign in here:

- **Onboarding / apply:** https://dashboard.asklear.cn/beta

Once your account is approved and you sign in, the Dashboard issues your MCP endpoint address and API Key. **These are not published in this repository** — they are provisioned per account after login. Usage and billing follow the terms of each account.

## Connecting

Configure your MCP client with the endpoint and Bearer key shown on your Dashboard after login. The onboarding page walks through client-specific setup and keeps the tool list, parameters, and error reference current.

# Asklear MCP Server（中文）

Asklear MCP 目前提供京东月度电商销售数据。其他数据集可能根据用户的接入资格开放。

Asklear 提供托管的 [Model Context Protocol](https://modelcontextprotocol.io)（MCP）服务，获授权的 AI Agent 可查询结构化的中国月度电商销售数据，包括券后销售额（GMV）、销量和平均成交价。

## 获取接入

Beta 阶段采用邀请或申请制，审核通过后方可接入。在此申请或登录：

- **接入 / 申请：** https://dashboard.asklear.cn/beta

账户通过审核并登录后，Dashboard 会签发你的 MCP 接入地址和 API Key。**这些信息不发布在本仓库**，按账户登录后单独下发。用量与计费以各账户的条款为准。

## 连接

用登录后 Dashboard 上显示的接入地址与 Bearer Key 配置你的 MCP 客户端。接入页会引导各客户端的具体配置，并保持工具清单、参数与错误码参考的更新。
