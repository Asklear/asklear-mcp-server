# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** through GitHub's private vulnerability reporting:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the issue, affected surface, and reproduction steps.

Do **not** open a public issue for security reports.

We aim to acknowledge reports within a reasonable time and will coordinate disclosure with you.

> Note: this repository is a public documentation/adoption shell — it contains no service code, keys, or endpoints. Vulnerabilities in the hosted Asklear MCP service or in your account access should also be reported through the channel above.

# 安全策略（中文）

## 漏洞上报

请通过 GitHub 的私密漏洞上报渠道**私下**提交安全漏洞：

1. 进入本仓库的 **Security（安全）** 标签页。
2. 点击 **Report a vulnerability（上报漏洞）**。
3. 描述问题、受影响面与复现步骤。

请**不要**用公开 issue 提交安全问题。

我们会在合理时间内确认,并与你协调披露。

> 说明：本仓库是公开的文档/引流外壳,不含任何服务代码、密钥或接入地址。托管的 Asklear MCP 服务或账户接入相关的漏洞,同样请通过上述渠道上报。
